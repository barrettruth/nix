# nvim-build

Build the Neovim checkout in the shell's current directory.

If Barrett names a branch or worktree, `cd` to that checkout first.

Run:

```sh
~/.config/nix/config/skills/nvim-build/scripts/build
```

Report the result and the printed log path.
